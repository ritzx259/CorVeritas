## Model comparison metrics update

The records in `evaluations/` populate all six metrics for the saved MLP, CNN
and Random Forest. They were generated by `scripts/record_evaluation_metrics.py`
from the current dataset and frozen artifacts, with the splits and thresholds
inspected from the original scripts. MLP scores are **validation** scores on
184 rows used during training monitoring; CNN and Random Forest scores use
184-row **test** partitions. No model was retrained or selected using these
results. Earlier delivery checks above predate this evaluation update.

Each record identifies its exact source, data and artifact hashes. The API
serves a record only when the data and loaded artifact files match. Historical
artifact hashes in `original-files.sha256.json` describe the earlier delivery;
the evaluation JSON files record the current artifacts independently.

For this update, backend/training tests: **55 passed**; frontend tests:
**11 passed**; production build: **passed**. Tests include the real `/api/models`
response, rejection of records for changed models/preprocessors/data, metric
formula checks, and correct validation/test labels in the comparison table.
